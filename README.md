## Accuracy of repository contents

A folder formerly called `ML/House Price Prediction` duplicated the exact customer-segmentation notebook and dataset, while its README incorrectly described house-price regression. That mislabeled duplicate is removed in this change; no actual house-price predictor is presented as completed. The Airbnb price prediction notebook is the available regression example.

A model trained in a notebook is not by itself evidence of a deployed, monitored ML service.
